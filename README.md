# 🎵 Music Streaming Web Application

A Spotify-like music streaming application built with Django, featuring user authentication, playlists, OTP verification, and mobile-responsive UI.


## 🚀 Features
- User registration + login
- OTP-based authentication
- Playlist creation
- Audio streaming


## 🛠 Tech Stack
- Backend: Django, Python
- Frontend: HTML, CSS, Bootstrap, JavaScript
- Database: SQLite


## 📦 Installation
git clone https://github.com/varshanixon/music-streaming-app  
cd music-streaming-app  
pip install -r requirements.txt  
python manage.py migrate  
python manage.py runserver
